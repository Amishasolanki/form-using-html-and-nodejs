# 🚀 Full-Stack Form Application with EJS Server-Side Rendering

## 📋 Project Overview
A comprehensive web application built with Node.js, Express, and EJS featuring dynamic form handling and admin dashboard.

## ⚡ Quick Start
```bash
git clone <your-repo-url>
cd <your-repo-name>
npm install
npm start
```
🌐 **Visit:** http://localhost:3000

## 🎯 Key Features
- **📝 Dynamic Forms** - 15+ input types with validation
- **📊 Admin Dashboard** - Real-time statistics & analytics
- **🔍 Search & Filter** - Find submissions instantly
- **📥 Data Export** - JSON/CSV download functionality
- **📱 Responsive Design** - Mobile-friendly interface
- **⚡ Server-Side Rendering** - Fast, SEO-optimized pages

## 🛠 Tech Stack
- **Backend:** Node.js, Express.js
- **Frontend:** EJS Templates, CSS3, JavaScript
- **Validation:** Joi
- **Data:** In-memory storage (production: database ready)
- **Tools:** Nodemon for development

## 📁 Project Structure
```
├── server.js          # Main Express server
├── package.json       # Dependencies & scripts
├── views/             # EJS templates
│   ├── form.ejs       # Main form page
│   ├── admin.ejs      # Admin dashboard
│   └── message.ejs    # Success/error pages
└── README.md          # Documentation
```
